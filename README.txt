TWICA Documents — Official-logo PWA

This version uses the actual Masjid Al-Noor logo embedded in the document generator.
The separate DOCS badge uses the same teal, gold and cream brand palette.

Upload all files in this folder together to the same HTTPS web folder.
Then open index.html on your Samsung/Android browser and choose Install app / Add to Home screen.
The app will appear as TWICA Docs and launch standalone.

Opening index.html directly from Downloads will not provide full PWA installation because installation/service workers require HTTPS (or localhost).
Document History remains local to the browser/device.
